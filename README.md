# 🍸 Sip n Swipe

**Sip n Swipe** is a fun and modern iOS app that lets users explore cocktail recipes with a swipe-based interface—like Tinder, but for drinks! Swipe right to save your favorites and tap to view details like ingredients and preparation steps.

## 📱 Features

- Swipe left or right to explore cocktails
- Tap a card to view ingredients and drink details
- Save favorite cocktails to your personal recipe list
- Clean, modern UI built with SwiftUI
- Powered by [TheCocktailDB API](https://www.thecocktaildb.com)

## 🚀 Getting Started

### Prerequisites

- Xcode 15+
- iOS 16.0+
- SwiftUI

### Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/ajmastra/sip-n-swipe.git
   ```
2. Open the project in Xcode:
   ```bash
   open sip-n-swipe.xcodeproj
   ```
3. Build and run on your simulator device.

## 📦 Technologies Used

- Swift & SwiftUI — for app structure and UI

- Combine — for reactive data binding

- TheCocktailDB API — for cocktail data

- MVVM Architecture — for clean separation of logic and UI
